SSX for Switch

Builds the Nintendo Switch package of SSX from your own copy of the Android game. Everything runs in this browser: nothing is uploaded.

1. Choose your APK

Nothing chosen yet.

2. Create the package

The zip holds the Switch program, your APK, README.txt and sample settings, in switch//. It downloads while it is written (about 1.3 GB, mostly your APK). Use a Chromium-based browser (Chrome, Edge, Brave) or Firefox.

3. Copy it to the Switch

You need a Switch running Atmosphere, with sphaira, and about 2.2 GB free on the SD card.

  1. Extract the zip to the root of the SD card: it makes switch//.
  2. On the Switch, open sphaira. It installs nothing until installing is turned on: Menu (Y) > Advanced Options > Install options > Enable emummc (or sysmmc). sphaira warns that installing apps can get a console banned: emuMMC, kept offline, is the safe way.
  3. In sphaira's Homebrew list, select SSX, press X and choose Install Forwarder, then Create Forwarder. An SSX icon appears on the HOME menu.
  4. Start the game from that icon. The first start takes a few minutes: it installs itself, restarts, and copies the game's music and movies out of the APK. Later starts are quick.
  5. README.txt in the folder has the controls, the settings, updating and removing it.
