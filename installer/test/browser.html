worker.js in a browser

Run python serve.py 8642 . --test-files <folder with the APK> --test-out <zip> and open /test/browser.html. The worker makes the zip from the served APK (read with HTTP range requests, as the page reads its File) and the zip goes to the server's --test-out file in 8 MB writes, for test/check_zip.py. The zip holds the APK: game data, never commit or share it.
